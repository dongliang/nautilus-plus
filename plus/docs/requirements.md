# 原始需求

让文件管理器按**文件夹内的项目元数据**(`.folder.yaml`)增强显示与组织,便于项目整理:

- **显示描述**:文件夹可显示一段自定义描述(中文或任意语言),磁盘上的真实名字和路径不变。**方案已定(2026-08-17)**:采用 caption 第二行显示(真名在上、描述在下),不做显示名替换;2026-09-25 起该字段统一称「描述」(`desc`)——理由见 `research.md`
- **项目状态**:标记文件夹状态(如归档/进行中),可控制显示方式
- **可折叠分组**:按状态/类型把文件夹分组显示,带分隔线和折叠标题
- **全局开关**:右键菜单切换各项功能的开关,即时生效
- **实现策略**:先以 nautilus-python 插件实现;扩展 API 能力不足的部分,由 fork 提供 C 层钩子补足
